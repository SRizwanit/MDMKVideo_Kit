# 🎬 MDMK ভিডিও টুলকিট (খসড়া — ধাপ ১)

`mdmk.mp4` + `timestamp.json` থেকে ক্যাশপন ক্যাপশন ও ইনফোগ্রাফিক সহ ভিডিও রেন্ডার করার প্রজেক্ট (Remotion)।
পূর্ণ পরিকল্পনা ও অগ্রগতি দেখো: [`mdmk.md`](./mdmk.md)

> ⚠️ এটি খসড়া। ধাপ ৭-এ মোবাইল-নির্দেশিকা ও GitHub Actions যোগ হয়েছে; চূড়ান্ত পলিশ ধাপ ৮-এ।

## ইনপুট ফাইল (রুটে, নাম ফিক্সড)

| ফাইল | কাজ |
|------|------|
| `mdmk.mp4` | মূল ভিডিও |
| `timestamp.json` | শব্দ-ভিত্তিক টাইমস্ট্যাম্প (`metadata` + `transcript` + `words[]`) |

নতুন ভিডিওর জন্য একই নামে **Replace** করে আপলোড করবে।

## কম্পিউটারে চালানো (ঐচ্ছিক)

```bash
npm install
npm run preview   # Remotion Studio (ব্রাউজারে প্রিভিউ)
npm run still     # টেস্ট ফ্রেম → test-frame.png
npm run render    # পূর্ণ রেন্ডার → out.mp4
```

## ফ্ল্যাট স্ট্রাকচার

সব সোর্স রুটে। একমাত্র ব্যতিক্রম: `.github/workflows/render.yml` (GitHub Actions বাধ্যতামূলক পাথ — ধাপ ৭ ✅)।
Remotion `publicDir` রুটে সেট (`remotion.config.ts`)। Next.js ঐচ্ছিক; রেন্ডারে লাগে না।

## ইনফোগ্রাফিক SVG (ধাপ ৫) ও সাউন্ড ইফেক্ট

- `svg1.tsx … svg9.tsx` — ৯টি অ্যানিমেটেড ইনফোগ্রাফিক (এই ভিডিওর টপিকের জন্য); `svgRegistry.tsx`-এ তালিকা। স্টুডিওতে (`npm run preview`) `Svg1 … Svg9` কম্পোজিশনে আলাদা দেখা যায়; `npm run still:svgs` সবগুলোর স্টিল বানায়।
- `sfx1.wav … sfx12.wav` — ছোট সাউন্ড ইফেক্ট (পপ, সুইশ, পানির ফোঁটা, টিক, হুশ, থাড, ঝিলিক, পাতা-ওল্টানো, টিং, বাবল, স্ন্যাপ, রাইজার)। কোনো গান/সুর নেই। পরপর দুবার একই সাউন্ড বাজে না; প্রতিটি ভিডিওর ক্রম আলাদা (`sfxPicker.ts`)। নিজের সাউন্ড দিতে একই নামে `sfxN.wav` রিপ্লেস করো। (সাউন্ড বসানো ধাপ ৬.৩-এ।)

বাংলা ফন্ট: **Baloo Da 2** (প্রাইমারি), ফলব্যাক Hind Siliguri → Noto Sans Bengali। বদলাতে `theme.ts`-এর শুরুর `BANGLA_PRIMARY_*` ধ্রুবক বদলাও।

## লেআউট (ধাপ ৬.১)

ইনফোগ্রাফিক কার্ডের নিচের সীমা ≈ y ৬৩৫ (বক্তার চুলের রেখা ≈ ৫৭০-এর কাছাকাছি, চোখ-কপাল খোলা)। কার্ড ৬৯০px চওড়া, নিরাপদ-এলাকার মাঝে। মাপের ধ্রুবক: `theme.ts` (`CARD_BOTTOM`, `zones`, `faceRef`) ও `svgKit.tsx` (`BODY_SCALE`, `STAGE_SCALE`)।

## ডিরেক্টর ও ইফেক্টস (ধাপ ৬.২)

- `director.ts` — `timestamp.json`-এর শব্দ-সময় থেকে পুরো ভিডিও সাজায় (বিশুদ্ধ TypeScript; `npm run test:director`)।
  - **কাস্টম-মোড:** এই ভিডিও (ইস্তিঞ্জার সুন্নাত ৯–১২) — সময়-সীমা → `svg1…svg9` (কেবল শব্দ-সময় মিললে চলে)।
  - **অটো-মোড:** নতুন ভিডিও — "আসসালামু আলাইকুম" → সালাম ব্যাজ; "এক/দুই/… নাম্বার" → নম্বর-কার্ড (বাক্যের শিরোনাম + আইকন); "ষোলটি … আটটি" → রিং ৮/১৬; "পরবর্তী চারটি" → "+৪"; "MDMK" → ব্র্যান্ড-ব্যাজ; "সুন্নাত … শিখি" → বই-সিন।
  - মোড বদলাতে `director.ts`-এর `DIRECTOR_MODE` (`'detect'` ডিফল্ট / `'custom'` / `'auto'`)।
  - আউটপুটে SFX-র জন্য ইভেন্ট-তালিকা (`plan.events`) ও ১-সেকেন্ডে-১-টি ছাঁটাই (`thinEvents`) — ধাপ ৬.৩-এর `SfxLayer` এটাই ব্যবহার করে।
- `Effects.tsx` — ধীর পাঞ্চ-জুম (১.০৪ → ১.০৮, কেন্দ্র y ≈ ৬০০ — মাথার উপরে), উপরের হালকা গ্লো/গ্র্যাডিয়েন্ট, সিনের শুরুতে সোনালি ফ্ল্যাশ।
- `AutoScenes.tsx` — অটো-মোডের জেনেরিক কার্ড (`AutoPointCard`, `AutoCountCard`)।
- `Video.tsx` — লেয়ার: ভিডিও(জুম) → ইফেক্টস → সিন-কার্ড → ট্র্যাকার → নম্বর-ব্যাজ → ক্যাপশন → ইন্ট্রো/আউট্রো (ধাপ ৬.৩) → SFX অডিও (ধাপ ৬.৩)।
- মূল `MDMK` কম্পোজিশনের স্টিল: `npm run still:mdmk` (সিন ১, ৪, ৬, ৭, ৯)।

## SFX লেয়ার ও ইন্ট্রো/আউট্রো (ধাপ ৬.৩)

- `SfxLayer.tsx` — ডিরেক্টরের ইভেন্টে `sfxN.wav` বাজায় (ভলিউম ০.৩৫, ১ সেকেন্ডে ১টি, পরপর একই নয়, ভিডিওভেদে ভিন্ন ক্রম, একই ভিডিওতে স্থির)। **বন্ধ করতে:** `SfxLayer.tsx`-এর `SFX_ENABLED = false`।
- `sfxPlan.ts` — কোন ফ্রেমে কোন সাউন্ড তার হিসাব (বিশুদ্ধ TS)। সিড = `timestamp.json`-এর টেক্সট-হ্যাশ (`Root.tsx` দেয়)। ভলিউম বদলাতে `SFX_VOLUME`।
- `IntroOutro.tsx` — **ইন্ট্রো:** শুরুতে উপরে ছোট পটি (আইকন + `MDMK` + বিষয়); **আউট্রো:** শেষ কার্ডের পর "MDMK এর সাথে থাকুন" কার্ড (লোগো-ব্যাজ + ফলো-বাটন + বেল)। **নতুন ভিডিওতে ফাইলের শুরুর `INTRO_SUBTITLE` বদলাও** (খালি `''` = শুধু ব্র্যান্ড); `BRAND`, `OUTRO_TITLE`, `OUTRO_SUBTITLE`, `OUTRO_BUTTON`-ও এখানে।
- `introOutroPlan.ts` — ইন্ট্রো/আউট্রোর সময় (বিশুদ্ধ TS): ইন্ট্রো ট্র্যাকারের আগে শেষ; আউট্রো শেষ কার্ডের পর, জায়গা ৩৬ ফ্রেমের কম হলে বাদ।
- টেস্ট: `npm run test:layers` (Remotion লাগে না)। টাইপ-চেক: `npm run typecheck`।
- পূর্ণ ভিডিওর দ্রুত লো-কোয়ালিটি টেস্ট-রেন্ডার: `npm run render:lowq` → `test-full-lowq.mp4` (স্কেল ০.৩৫, কম কোয়ালিটি)।

## 📱 মোবাইলে ভিডিও বানানো (GitHub Actions — ধাপ ৭)

১. রিপো খোলো → **`mdmk.mp4`** ট্যাপ → ⋯ (তিন-ডট) → **Delete/Replace**; সহজ উপায়: রিপোর হোমে **Add file → Upload files** → নতুন `mdmk.mp4` ও `timestamp.json` বেছে নাও (একই নামে, রুটে)।
২. নিচে **Commit changes** ট্যাপ করো — রেন্ডার **অটো শুরু** হবে।
৩. উপরের **Actions** ট্যাব → সবচেয়ে উপরের রান (হলুদ = চলছে, সবুজ ✓ = শেষ, লাল ✗ = ব্যর্থ)।
৪. শেষ হলে রানের পেজের **সামারি**-তে **out.mp4** লিংক ট্যাপ করে ডাউনলোড। বিকল্প: রিপোর হোমে **Releases** → সর্বশেষটা → **Assets → out.mp4**।
৫. অটো না চললে বা আবার চালাতে: **Actions → MDMK ভিডিও রেন্ডার → Run workflow → Run workflow**।

> ফাইল **রুটে** (কোনো ফোল্ডারে নয়) থাকতে হবে। `package-lock.json` না থাকলেও চলে।
> প্রথমবার বেশি সময় লাগে (ডিপেন্ডেন্সি ও ব্রাউজার নামে); পরের বার ক্যাশের কারণে দ্রুত।

**সমস্যা হলে (সংক্ষেপে):**
- **ইনপুট যাচাই ধাপে লাল ✗** → বাংলা এররে যা লেখা আছে (ফাইল নেই / JSON ভুল / `sfxN.wav` নেই) তাই ঠিক করে আবার আপলোড।
- **Release-এ "Resource not accessible"** → রিপো **Settings → Actions → General → Workflow permissions → Read and write permissions** দাও, তারপর Run workflow।
- **রেন্ডারে টাইমআউট/মেমরি/ফন্ট লোড ব্যর্থ** → লগ পড়ো; সাধারণত আবার Run workflow দিলে (নেটওয়ার্ক-সাময়িক সমস্যা) ঠিক হয়।
- ওয়েব আপলোডে ফাইল ২৫ MB-এর কম রাখা ভালো।
